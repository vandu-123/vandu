### Experiment: Extracting and Analysing Windows Registry and USB Artifacts

### 1\. Procedure

* Switch on the forensic workstation.

* Open the forensic tool (Autopsy or Registry Explorer).

* Load the Windows forensic image or registry hive files.

* Locate the Windows Registry files.

* Identify important registry hives such as SYSTEM, SOFTWARE, SAM, SECURITY and NTUSER.DAT.

* Examine the registry keys and values related to system configuration and user activity.

* Navigate to the USB device-related registry entries.

* Identify connected USB device information, including device name, vendor ID and product ID.

* Examine USB connection details and available timestamps.

* Analyse the extracted artifacts to identify previously connected USB devices.

* Record the findings and save the forensic analysis report.

### 3\. Important Windows Registry Hives

| Registry Hive | Purpose                               |
| ------------- | ------------------------------------- |
| SYSTEM        | Hardware and system configuration     |
| SOFTWARE      | Installed software information        |
| SAM           | User account information              |
| SECURITY      | Security policies                     |
| NTUSER.DAT    | Individual user settings and activity |

### 4\. Important USB Artifacts

* USBSTOR: Stores information about USB storage devices.

* USB Device ID: Identifies the connected USB device.

* Vendor ID (VID): Identifies the device manufacturer.

* Product ID (PID): Identifies the device model or product.

* Serial Number: Helps identify a particular device.

* Last Write Time: Indicates when a registry key was last modified.

### 5\. Result

Windows Registry hives were successfully extracted and analysed. USB artifacts were identified, and information such as device name, vendor ID, product ID, serial number and available timestamps was examined to determine USB device connection history.

### Common Windows Registry Commands (CMD)

These are important commands for your Digital Forensics practical and viva.

| Command     | Purpose                              |
| ----------- | ------------------------------------ |
| regedit     | Opens Registry Editor                |
| reg query   | Displays registry keys and values    |
| reg add     | Adds a registry key or value         |
| reg delete  | Deletes a registry key or value      |
| reg export  | Exports registry keys to a file      |
| reg import  | Imports registry files               |
| reg save    | Saves a registry hive                |
| reg load    | Loads a saved registry hive          |
| reg unload  | Unloads a loaded registry hive       |
| reg compare | Compares registry subkeys and values |
| reg copy    | Copies registry entries              |

### Important practical commands

1\. Open Registry Editor

```cmd
regedit
```

2\. View USB device history

```cmd
reg query HKLM\SYSTEM\CurrentControlSet\Enum\USBSTOR
```

3\. View connected USB device information

```cmd
reg query HKLM\SYSTEM\CurrentControlSet\Enum\USB
```

4\. View installed software

```cmd
reg query HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall
```

5\. View Windows version

```cmd
reg query "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion"
```

6\. Export a registry key

```cmd
reg export HKLM\SYSTEM C:\SYSTEM.reg
```
