
Procedure (Linux Part – User Authentication and Access Control)

1. Open Terminal and Verify Current User. Open the Terminal in Kali Linux and execute whoami to verify the currently logged-in user account.
2. Create a New User Account. Run sudo adduser student1 to create a new user. Set and confirm the password, press Enter to skip optional profile details, and type Y to confirm. Verify the user creation with id student1.
3. Test User Authentication. Run su - student1 and enter the newly created password. Execute whoami to confirm the active session switched to student1, then run exit to return to the primary account.
4. Create a User Group. Run sudo groupadd dfisusers to create a new group. Verify the group entry in the system database using getent group dfisusers.
5. Add User to the Group. Execute sudo usermod -aG dfisusers student1 to assign student1 to the dfisusers group. Verify membership using groups student1 or id student1.
6. Refresh Group Session. Switch to the user account with su - student1 (or log out and log back in) so the new group membership takes effect. Run groups to verify dfisusers appears in the active session, then type exit.
7. Create a Protected Directory. From the administrative account, create a shared folder using sudo mkdir /dfisdata and inspect its default permissions using ls -ld /dfisdata.
8. Assign Directory Ownership. Change the owner to student1 and the group to dfisusers by running sudo chown student1:dfisusers /dfisdata. Confirm the ownership change with ls -ld /dfisdata.
9. Configure Access Control Permissions. Restrict directory permissions using sudo chmod 770 /dfisdata so only the owner (rwx) and group (rwx) have full access while others (---) have no access. Verify with ls -ld /dfisdata (drwxrwx---).
10. Verify Directory and File Access. Switch to student1 using su - student1, navigate into the directory with cd /dfisdata, create a test file using touch test.txt, and verify write permissions with ls -l.
11. Demonstrate Authentication vs. Access Control. Verify identity authentication via su - student1 (password check confirming who the user is), and verify authorization/access control via cd /dfisdata and touch test.txt (permission check confirming what the user is allowed to do).

Result

User authentication and discretionary access control were successfully implemented and verified on Kali Linux. A new user (student1) and group (dfisusers) were created, directory ownership and 770 (rwxrwx---) permissions were configured on /dfisdata, and access rights were validated by authenticating as the user and creating a file inside the protected directory.
