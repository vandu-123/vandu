### File System Analysis – FAT32, NTFS and EXT4 (Theory)

### 1\. Introduction

A file system is a method used by an operating system to organize, store, manage and retrieve files on storage devices such as hard disks, SSDs and USB drives.

The three commonly used file systems are FAT32, NTFS and EXT4.

### 2\. FAT32 (File Allocation Table 32)

FAT32 is a file system developed by Microsoft. It is commonly used in USB drives, memory cards and external storage devices.

Features:

* Uses a File Allocation Table to track file locations.

* Supports different operating systems.

* Maximum individual file size is 4 GB minus 1 byte.

* Does not support journaling.

* Has limited file permission features.

Main components:

* Boot Sector – Contains file system information.

* FAT Table – Tracks file allocation.

* Root Directory – Stores directory entries.

* Data Area – Stores actual file contents.

### 3\. NTFS (New Technology File System)

NTFS is a file system developed by Microsoft. It is commonly used in Windows operating systems.

Features:

* Uses Master File Table (MFT) to store file information.

* Supports large files and storage volumes.

* Provides file permissions and access control.

* Supports file compression and encryption.

* Supports journaling for file system consistency.

Main components:

* Boot Sector – Contains file system information.

* MFT – Stores file and directory records.

* File Records – Store file attributes and metadata.

* Data Runs – Describe the locations of file data.

* $LogFile – Maintains file system transaction records.

### 4\. EXT4 (Fourth Extended File System)

EXT4 is a Linux file system commonly used in Linux operating systems. It is an improved version of EXT3.

Features:

* Supports large files and storage volumes.

* Uses inodes to store file metadata.

* Supports journaling.

* Uses extents for efficient storage allocation.

* Provides improved performance and reliability.

Main components:

* Superblock – Stores important file system information.

* Block Groups – Organize storage into groups.

* Inode Table – Stores file metadata.

* Data Blocks – Store actual file contents.

* Journal – Records file system changes.

### 5\. Comparison of FAT32, NTFS and EXT4

| Features         | FAT32                    | NTFS                       | EXT4                        |
| ---------------- | ------------------------ | -------------------------- | --------------------------- |
| Full form        | File Allocation Table 32 | New Technology File System | Fourth Extended File System |
| Common OS        | Multiple OS              | Windows                    | Linux                       |
| Main structure   | FAT                      | MFT                        | Inodes                      |
| Journaling       | No                       | Yes                        | Yes                         |
| File permissions | Limited                  | Yes                        | Yes                         |
| File size limit  | Nearly 4 GB              | Very large                 | Very large                  |
| Common usage     | USB drives               | Windows drives             | Linux drives                |

### 6\. Importance in Digital Forensics

File system analysis is important in digital forensics because it helps investigators:

* Identify deleted files.

* Recover digital evidence.

* Examine file metadata and timestamps.

* Identify hidden files and folders.

* Analyse unallocated disk space.

* Understand file storage and allocation mechanisms.

### 7\. Conclusion

FAT32, NTFS and EXT4 are important file systems used by different operating systems and storage devices. Understanding their structures and features helps digital forensic investigators examine storage devices, analyse file metadata and recover deleted data.
