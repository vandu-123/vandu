### Experiment: Simple Intrusion Detection System (IDS) Using Bash Scripting

### 1\. Procedure

* Open the Kali Linux terminal.

* Create a new Bash script using the command:

    ```bash
    nano ids.sh
    ```

* Write a Bash script to monitor network connections and detect suspicious activity.

* Save the script and exit the editor.

* Give execution permission:

    ```bash
    chmod +x ids.sh
    ```

* Execute the script:

    ```bash
    ./ids.sh
    ```

* The script checks the active network connections.

* Identify unusual connections or suspicious network activity.

* Display an alert when suspicious activity is detected.

* Record the detected activity and observations.

### 2\. Sample Bash Script

```bash
#!/bin/bash

echo "Simple Intrusion Detection System"
echo "--------------------------------"

echo "Checking active network connections..."

connections=$(ss -tun)

echo "$connections"

echo "--------------------------------"
echo "Checking failed login attempts..."

if [ -f /var/log/auth.log ]; then
    grep "Failed password" /var/log/auth.log | tail -5
else
    echo "Authentication log not available"
fi

echo "--------------------------------"
echo "IDS Scan Completed"
```

### 3\. Important Commands

| Command         | Purpose                       |
| --------------- | ----------------------------- |
| nano ids.sh     | Creates or edits a script     |
| chmod +x ids.sh | Gives execution permission    |
| ./ids.sh        | Executes the script           |
| ss -tun         | Displays network connections  |
| grep            | Searches for matching text    |
| tail -5         | Displays the last five lines  |
| echo            | Displays messages             |
| if              | Performs conditional checking |
