### Practical: System Log Analysis Using GREP, AWK and SED Commands to Identify Login Activities in Linux

### 1\. Aim

To analyse Linux system log files using `grep`, `awk`, and `sed` commands to identify user login activities and failed login attempts.

### 2\. Requirements

* Kali Linux / Ubuntu

* Terminal

* System log files (`/var/log/auth.log`)

### 3\. Procedure

Step 1: Open the terminal.

Step 2: View authentication logs.

```bash
sudo cat /var/log/auth.log
```

Step 3: Identify successful login activities using GREP.

```bash
sudo grep "Accepted" /var/log/auth.log
```

Step 4: Identify failed login attempts using GREP.

```bash
sudo grep "Failed password" /var/log/auth.log
```

Step 5: Display login activities using AWK.

```bash
sudo awk '/Accepted/ {print $1,$2,$3,$9,$11}' /var/log/auth.log
```

Step 6: Display failed login attempts using AWK.

```bash
sudo awk '/Failed password/ {print $1,$2,$3,$9,$11}' /var/log/auth.log
```

Step 7: Filter login-related entries using SED.

```bash
sudo sed -n '/Accepted/p' /var/log/auth.log
```

Step 8: Display the last login information.

```bash
last
```

Step 9: Display failed login records.

```bash
sudo lastb
```

### 4\. Observation

| Command                | Observation                             |
| ---------------------- | --------------------------------------- |
| grep "Accepted"        | Displays successful login entries       |
| grep "Failed password" | Displays failed login attempts          |
| awk                    | Extracts selected log fields            |
| sed                    | Filters login-related log entries       |
| last                   | Displays previous login sessions        |
| lastb                  | Displays recorded failed login attempts |

### 5\. Result

Linux system logs were successfully analysed using GREP, AWK and SED commands to identify successful logins, failed login attempts and user login activities.
