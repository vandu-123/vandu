### Experiment: Browser Analysis and Google Takeout Cache

### 1\. Procedure

A. Browser Analysis

* Switch on the forensic workstation.

* Open a forensic tool such as Autopsy.

* Load the browser forensic image or collected browser data.

* Locate the browser profile folder.

* Identify browser databases and files such as History, Cookies, Downloads and Web Data.

* Examine browsing history to identify visited websites.

* Analyse download history to identify downloaded files.

* Examine cookies and cached files.

* Identify timestamps associated with browsing activities.

* Record the extracted browser artifacts.

B. Google Takeout Analysis

* Open Google Takeout.

* Select the required Google data categories.

* Choose the export format (ZIP).

* Create and download the data archive.

* Extract the downloaded ZIP file.

* Open the extracted folders.

* Examine browser-related and Google account activity data included in the export.

* Analyse available HTML and JSON files.

* Examine timestamps, search activity and other available records.

* Record the findings.

C. Cache Analysis

* Locate the browser cache folder in the collected browser profile.

* Examine the cached files using a forensic tool.

* Identify cached images, scripts, web pages and other resources.

* Examine file names, sizes and available timestamps.

* Correlate cache entries with browsing history.

* Record the observations.
